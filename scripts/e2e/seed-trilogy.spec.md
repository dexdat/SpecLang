# The Salt Chorus - Trilogy Expansion

## Intent

You are expanding the seed spec for a complete standalone trilogy project.
From THIS one spec, generate every artifact the project needs:

1. `generated/structure.md` - the trilogy architecture: three books, twenty
   chapters each, named acts, and the arc of the tide-calendar world.
2. `generated/characters.md` - the character bible: the Vane siblings
   (Kestrel "Kes", Iona, Tanner "Tan"), their antagonists, and every named
   supporting role, each with want/wound/arc.
3. `generated/locations.md` - the location bible: every place in the
   memory-salt economy, from the tide farms to the Salt Archive.
4. `generated/book-one-chapters.md` - Book One's twenty-chapter map, one
   hook per chapter, POV assignments, midpoint reversal, end state.
5. `generated/book-one-chapter-01.md` - Chapter One in full prose (~2000
   words), opening on the tide going out.

## Rules

- Every file under generated/ must be complete, non-empty, and consistent
  with the others (same names, same timeline).
- Do not invent new protagonists.
- Work file by file; write each file as soon as it is complete.
