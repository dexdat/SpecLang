## Current state

## The spec (specs/dashboard.spec.md)
The dashboard spec defines four component groups:
- handlers/ — event handlers for dashboard interactions
- hooks/ — React hooks for dashboard state  
- interactions/ — user interaction components
- styles/ — dashboard styling

## What to build
1. Read specs/dashboard.spec.md thoroughly — understand the full component requirements
2. Check the cascade status spec (@ref:specs/cascade) for the data model to display
3. Build React components for:
   a. SpecList — list all specs with their status (draft/active/generated/etc)
   b. CascadeStatus — show current cascade state (running/idle/converged)
   c. HealthGauge — visual health metrics (total specs, implementation ratio, layers)
   d. LayerChart — bar chart of specs per layer
4. Use the health monitor module (specs/health/assembled/health-core.spec.ts) for data — it already scans 445 specs and computes metrics
5. Wire into Vite (vitest.config.ts already includes the test)
6. After build, dist/dashboard/ should have index.html + JS bundle with interactive dashboard
