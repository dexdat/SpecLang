AC-043: Fix Vite Dashboard Build

PROBLEM: `npx vite build` fails because compiled `.js` files in `specs/ui-dashboard.spec.dir/src/` contain spec header YAML (starting with `#;` etc.) which is NOT valid JavaScript. Vite/Rollup resolves these `.js` files instead of the `.tsx` sources, and fails at parse time because the content is invalid JS.

ROOT CAUSE: The spec directory has compiled JS output alongside TypeScript sources. The `.js` files were generated by tsc but placed in the specs directory, and they contain a `#;` spec header prefix that isn't valid JS.

TASK:
1. Remove ALL compiled `.js`, `.d.ts`, `.d.ts.map`, `.js.map` files from `specs/ui-dashboard.spec.dir/src/` and its subdirectories. These are build artifacts that should not be in the source tree.
  - Files to remove (use `find . -name '*.js' -o -name '*.d.ts' -o -name '*.js.map' -o -name '*.d.ts.map' | grep 'specs/ui-dashboard' | xargs rm`)
  - Do NOT remove `.tsx`, `.ts`, `.css` files — only the compiled output
  
2. Check `src/ui-dashboard/` symlinks — they point to `specs/ui-dashboard.spec.dir/src/`. Verify each symlink targets a `.ts` or `.tsx` file that exists (not a `.js` file).

3. Run `npx vite build` to verify the build now succeeds.

CRITICAL: Container has NO Python or Node runtime. DO NOT install anything. JUST delete the files and verify vite build.
