### 2. Add completion handler in `src/lsp/server.ts`

Add `completionProvider` to capabilities (triggerCharacters: ['@', '#'], resolveProvider: false).

Register `connection.onCompletion` that:
1. Gets current line text and cursor position
2. If cursor is after `@ref:` but before any `#` → return spec completions (filter by what's already typed after `@ref:`)
3. If cursor is after `@ref:something#` → resolve the `something` to a file, then return block completions from that file
4. If typing `@ref` or `@re` or `@r` (prefix of @ref:) → suggest `@ref:` as a snippet completion
5. Otherwise return empty

Add `completionItem` to imports from 'vscode-languageserver/node'.
