Implement go-to-definition for @ref: annotations in the SpecLang LSP server.

**Context:** The LSP server at `src/lsp/server.ts` currently provides diagnostics for spec headers. It needs go-to-definition support so users can Ctrl+click `@ref:specs/foo#block` annotations and jump to the referenced location.

**Reference format in .spec.md files:**
- File reference: `@ref:specs/core.spec.dir/entities` → resolves to `specs/core.spec.dir/entities.spec.md` or `specs/core.spec.dir/entities/`
- Block reference: `@ref:specs/core.spec.dir/entities#my-block` → resolves to the `### @block:my-block` block inside the spec
- Project reference: `@ref:northstar` → resolves to `docs/NORTH_STAR.md`

**Existing infrastructure:**
- `_index.json` (22,356 lines) in the project root maps spec IDs to file paths. Format:
  ```json
  { "specs": { "@specs/core": { "file": "specs/core.spec.md", "id": "@specs/core", "version": "...", "layer": 0 } } }
  ```
- The indexer at `src/indexer/index.ts` generates this and includes types in `src/indexer/types.ts`
- The LSP server lsp tsconfig at `src/lsp/tsconfig.json` with `"module": "Node16"` and `"moduleResolution": "node16"`

**Files to create/modify:**

**Implementation details:**

```typescript
// references.ts — key types
interface Reference {
  fullMatch: string;        // e.g. "@ref:specs/core#hello"
  refId: string;            // e.g. "specs/core"
  block?: string;           // e.g. "hello" (undefined for file refs)
  line: number;             // 0-based line in document
  startChar: number;        // 0-based character where @ref: starts
  endChar: number;          // 0-based character where @ref: ends
}

// Reference regex — matches @ref:path[#block]
const REF_REGEX = /@ref:([a-zA-Z0-9_\-/.]+)(?:#([a-zA-Z0-9_\-]+))?/g;

// File resolution rules:
// @ref:specs/core → specs/core.spec.md (check existence)
// @ref:specs/core.spec.dir/entities → specs/core.spec.dir/entities.spec.md
// @ref:northstar → docs/NORTH_STAR.md (hardcoded short names)
```

**The definition handler:**
```typescript
connection.onDefinition((params) => {
  const doc = documents.get(params.textDocument.uri);
  if (!doc) return null;
  
  const text = doc.getText();
  const line = params.position.line;
  const lineText = text.split('\n')[line] || '';
  
  // Find @ref: at or before cursor
  const refs = parseReferences(text);
  const target = refs.find(r => 
    r.line === line && 
    params.position.character >= r.startChar && 
    params.position.character <= r.endChar
  );
  
  if (!target) return null;
  
  const location = resolveReference(target, workspaceRoot);
  if (!location) return null;
  
  return {
    uri: `file://${location.filePath}`,
    range: {
      start: { line: location.line, character: location.character },
      end: { line: location.line, character: location.character }
    }
  };
});
```

**CRITICAL CONSTRAINTS:**
- Use `TextDocumentSyncKind.Full` for text sync (already configured)
