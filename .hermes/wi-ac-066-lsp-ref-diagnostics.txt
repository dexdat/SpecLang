### Validation flow:
```
validateReferences(text, workspaceRoot) → Diagnostic[]
  1. refs = parseReferences(text)
  2. for each ref:
     - resolved = resolveReference(ref, workspaceRoot)
     - if resolved === null → Diagnostic(Warning, ref range)
  3. return diagnostics
```
