You are tower-axiom. Build the DocumentSymbol provider for the SpecLang LSP.

## Context
The SpecLang LSP server (src/lsp/server.ts) currently supports: diagnostics, go-to-definition, hover, and completions. The next feature is AC-065: Document Symbols.

## What to build

### 1. Create src/lsp/symbols.ts
Implement these exported functions:

```typescript
export interface BlockSymbol {
  name: string;
  kind: string;
  line: number;        // 0-indexed line of the `### @block:` header
  endLine: number;     // 0-indexed line where this block's content ends (next block or EOF)
}

/**
 * Parse all blocks from a spec document.
 * Blocks are lines matching: ### @block:<name> @kind:<kind>
 * A block spans from its `### @block:` line until the next `### @block:` line or EOF.
 */
export function parseBlocks(text: string): BlockSymbol[]

/**
 * Build DocumentSymbol[] from a spec document's blocks for the LSP outline.
 * Includes:
 * - A SECTION symbol for the header (line 1 to closing ---)
 * - Each @block: as a child under a "Blocks" container, with kind mapped to SymbolKind:
 *   entity→Object, code→Function, note→String, directory→Module, default→Property
 */
export function getDocumentSymbols(text: string): DocumentSymbol[]
```

### 2. Integrate into src/lsp/server.ts
- Import `{ getDocumentSymbols }` from `./symbols.js`
- Add `documentSymbolProvider: true` to the capabilities
- Register `connection.onDocumentSymbol` handler:
  - Get the document text
  - Call `getDocumentSymbols(text)`
  - Return the symbols array

### 3. Export from src/lsp/index.ts
- Add: `export { parseBlocks, getDocumentSymbols } from './symbols';`
- Add: `export type { BlockSymbol } from './symbols';`
