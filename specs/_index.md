## Directory Conventions

- **`.spec.md`** - Markdown spec with YAML header
- **`.spec.yaml`** - Pure YAML spec
- **`.scl`** - Speclang format (like `project.scl`)
- **`.spec.dir/`** - Directory containing sub-specs
- **`_{name}.md`** - Index/meta files
- **`000-{name}.md`** - Bootstrap/primers (read first)

## Notes

- **Design specs** have `status: draft` or `status: active`
- **Index specs** have `children:` field listing sub-specs
- **Sub-specs** have `parent:` field referencing parent
