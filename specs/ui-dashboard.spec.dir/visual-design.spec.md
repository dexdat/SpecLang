# UI Dashboard Visual Design

Visual design system for the SpecLang dashboard.

## Design System

### @ui/design/system

Core design tokens and styling.

**Tokens:**
- Colors (primary, secondary, error, warning, success)
- Typography (font families, sizes, weights)
- Spacing (grid system, padding, margins)
- Shadows and elevations
- Border radius

## Component Library

### @ui/design/components

Reusable UI components.

**Components:**
- Buttons (primary, secondary, danger, ghost)
- Inputs (text, textarea, select, checkbox)
- Cards and panels
- Modals and dialogs
- Navigation (sidebar, tabs, breadcrumbs)
- Data display (tables, lists, trees)
- Feedback (alerts, toasts, progress)

## Theme Support

### @ui/design/themes

Light and dark theme support.

**Features:**
- Automatic system preference detection
- Manual theme toggle
- Custom theme configuration
- CSS custom properties for theming
