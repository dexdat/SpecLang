# SIP 44: Bootstrap Process

**Status:** Draft  
**Version:** 0.1.0  
**Author:** SpecLang Core Team

## README

This SIP defines Bootstrap Process—how SpecLang builds SpecLang (meta-circular bootstrap).

### Quick Start

Bootstrap phases:
1. Foundation: Core infrastructure (SQLite, headers, parser)
2. Core Runtime: Daemon, agents, cascade
3. MCP Interface: Editor integration
4. Code Generation: Spec-to-code compiler
5. Pipeline: Build automation
6. Meta-Circular: Self-hosting validation

### When to Read This

- **Bootstrapping**: Building SpecLang from scratch
- **Self-hosting**: Understanding meta-circularity
- **Recovery**: Fixing failed bootstrap

### Related SIPs

- SIP 0: What is SpecLang

## Abstract

This SIP defines the Bootstrap Process—the meta-circular process where SpecLang specs define how to build the system that reads those specs. Bootstrap proceeds in phases, each building on the previous, until the system can build itself.

## Motivation

SpecLang is self-specifying:
- specs/ define how to build the system
- The system reads specs/ to generate code
- Generated code becomes SpecLang

This creates a chicken-egg problem that bootstrap solves.

## Rationale

**Bootstrap approach:**

1. **Human writes minimal specs** (Tier 0)
2. **AI acts as compiler**, reading specs and generating code
3. **Generated code** becomes the SpecLang that reads specs
4. **System specs itself autonomously** (Tier 2+)

## Specification

### Bootstrap Phases

```yaml
BootstrapPhases:
  phase_0_foundation:
    description: "Core infrastructure"
    specs:
      - specs/sqlite.spec.md
      - specs/headers.spec.md
      - specs/project-layout.spec.md
    generates:
      - src/db/
      - src/parser/
      - src/indexer/
    validation:
      - "bun run tsc --noEmit"
      - "bun test tests/db.test.ts"
      - "_index.json exists and valid"
    can_proceed_if: "All tests pass, index generated"
    
  phase_1_core_runtime:
    description: "Reactive core: daemon and agents"
    depends_on: [phase_0_foundation]
    specs:
      - specs/daemon.spec.md
      - specs/agent-protocol.spec.md
      - specs/cascade.spec.md
    generates:
      - src/daemon/
      - src/agents/
      - src/cascade/
    validation:
      - "cargo build --release"
      - "bun test tests/agents.test.ts"
    can_proceed_if: "Daemon compiles, agents work"
    
  phase_2_mcp_interface:
    description: "Universal editor interface"
    depends_on: [phase_1_core_runtime]
    specs:
      - specs/mcp.spec.md
      - specs/mcp.spec.dir/*.spec.md
    generates:
      - src/mcp/
    validation:
      - "bun test tests/mcp.test.ts"
      - "MCP server responds to ping"
    can_proceed_if: "MCP server works"
    
  phase_3_code_generation:
    description: "Spec-to-code compiler"
    depends_on: [phase_2_mcp_interface]
    specs:
      - specs/compiler.spec.md
      - specs/stdlib.spec.md
    generates:
      - src/codegen/
    validation:
      - "Generate sample spec, verify output"
      - "bun test tests/codegen.test.ts"
    can_proceed_if: "Can generate working code"
    
  phase_4_pipeline:
    description: "Build automation and self-healing"
    depends_on: [phase_3_code_generation]
    specs:
      - specs/pipeline.spec.md
      - specs/recovery.spec.md
    generates:
      - src/pipeline/
      - src/recovery/
      - src/guard/
    validation:
      - "Run full pipeline on specs/"
      - "Verify convergence detection"
    can_proceed_if: "Full cascade converges"
    
  phase_5_meta_circular:
    description: "Self-hosting validation"
    depends_on: [phase_4_pipeline]
    specs:
      - specs/bootstrap.spec.md
    generates:
      - "Validation that specs/ generates system that reads specs/"
    validation:
      - "speclang build on this repo"
      - "Generated code compiles"
      - "All tests pass"
    can_proceed_if: "SpecLang builds itself"
```

### Rollback

```yaml
BootstrapRollback:
  on_phase_failure:
    1: "Log failure details to .speclang/bootstrap-failures.log"
    2: "Identify which spec caused failure"
    3: "Rollback generated files to last good state"
    4: "Notify north_star agent with error details"
    5: "Wait for spec fix or human intervention"
    
  recovery_commands:
    rollback_last_phase: "speclang bootstrap --rollback"
    retry_current_phase: "speclang bootstrap --retry"
    restart_from_scratch: "rm -rf src/ && speclang bootstrap"
    
  failure_modes:
    spec_ambiguous:
      detection: "Multiple interpretations of spec block"
      fix: "Add more detail to spec, add validation rules"
      
    circular_dependency:
      detection: "Spec A depends on B, B depends on A"
      fix: "Restructure specs, break circular refs"
      
    code_generation_error:
      detection: "Generated code doesn't compile"
      fix: "Fix spec, regenerate, validate"
```

## Implementation

```python
from dataclasses import dataclass
from typing import Optional
from enum import Enum
import subprocess
import os

class PhaseStatus(Enum):
    PENDING = "pending"
    IN_PROGRESS = "in_progress"
    COMPLETE = "complete"
    FAILED = "failed"

@dataclass
class BootstrapPhase:
    name: str
    description: str
    specs: list[str]
    generates: list[str]
    validation: list[str]
    depends_on: list[str] = None
    
class Bootstrapper:
    PHASES = [
        BootstrapPhase(
            name="foundation",
            description="Core infrastructure",
            specs=["specs/sqlite.spec.md", "specs/headers.spec.md"],
            generates=["src/db/", "src/parser/"],
            validation=["bun run tsc --noEmit", "bun test tests/db.test.ts"]
        ),
        BootstrapPhase(
            name="core_runtime",
            description="Daemon and agents",
            specs=["specs/daemon.spec.md", "specs/agent-protocol.spec.md"],
            generates=["src/daemon/", "src/agents/"],
            validation=["cargo build --release"],
            depends_on=["foundation"]
        ),
        BootstrapPhase(
            name="mcp_interface",
            description="Editor interface",
            specs=["specs/mcp.spec.md"],
            generates=["src/mcp/"],
            validation=["bun test tests/mcp.test.ts"],
            depends_on=["core_runtime"]
        ),
        BootstrapPhase(
            name="code_generation",
            description="Spec-to-code compiler",
            specs=["specs/compiler.spec.md"],
            generates=["src/codegen/"],
            validation=["bun test tests/codegen.test.ts"],
            depends_on=["mcp_interface"]
        ),
        BootstrapPhase(
            name="pipeline",
            description="Build automation",
            specs=["specs/pipeline.spec.md"],
            generates=["src/pipeline/"],
            validation=["speclang build --dry-run"],
            depends_on=["code_generation"]
        ),
    ]
    
    def __init__(self, project_root: str = "."):
        self.root = project_root
        self.completed: list[str] = []
        
    def run(self) -> bool:
        for phase in self.PHASES:
            if not self._can_proceed(phase):
                print(f"Skipping {phase.name}: dependencies not met")
                continue
                
            if not self._run_phase(phase):
                return False
                
            self.completed.append(phase.name)
            
        return True
        
    def _can_proceed(self, phase: BootstrapPhase) -> bool:
        if not phase.depends_on:
            return True
        return all(dep in self.completed for dep in phase.depends_on)
        
    def _run_phase(self, phase: BootstrapPhase) -> bool:
        print(f"Phase: {phase.name}")
        print(f"  {phase.description}")
        
        for cmd in phase.validation:
            result = subprocess.run(cmd, shell=True, cwd=self.root)
            if result.returncode != 0:
                print(f"  FAILED: {cmd}")
                return False
                
        print(f"  ✓ Complete")
        return True
        
    def rollback(self) -> None:
        if self.completed:
            last = self.completed.pop()
            phase = next(p for p in self.PHASES if p.name == last)
            for path in phase.generates:
                full_path = os.path.join(self.root, path)
                if os.path.exists(full_path):
                    subprocess.run(["rm", "-rf", full_path])
            print(f"Rolled back: {last}")
```
