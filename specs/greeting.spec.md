# Greeting Functions

Simple greeting utilities.

### @block::greet @kind:function

Returns a personalized greeting.

**Parameters:**
- name: string - Person to greet

**Returns:** string - Greeting message

**Example:**
```typescript
greet("World") // "Hello, World!"
```
